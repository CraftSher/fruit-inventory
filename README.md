# Fruit Inventory System

A simple Python project for managing fruit inventory in a warehouse. It allows users to view available fruits, add new items, remove products, and check low stock levels. This project demonstrates working with dictionaries, user input handling, and basic Python functionality.

## Features

- View current inventory of fruits
- Add fruits to the inventory
- Remove fruits from inventory
- Check fruits with low stock levels

## Technologies Used

- Python 3.x
- Dictionaries
- Loops, conditions, functions
- User input handling

## Example Usage

python inventory_manager.py

## Example output
Choose an action:
1 - Show products
2 - Add product
3 - Remove product
4 - Show products with low stock
0 - Exit
